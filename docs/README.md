## 文档边界

- 架构与执行细节维护在 `迭代升级/`；用户批准的版本历史只维护在 `迭代记录与问题.md`。
- 产品说明维护在根目录 `README.md`。

冲突时以机器可校验合同、代码、自动化测试、AI 执行入口和执行事实为准。用户未明确批准新版本前，不向迭代时间线追加内容。

用户视频、模型、缓存和生成文档不属于项目文档；不得在文档中复制 `.env` 或任何密钥。
