# 知影项目文档索引

本目录只保存产品、架构和实施说明。用户视频、模型、缓存、生成文档和发行包不属于项目文档，也不应提交到 Git。

## 当前优先阅读

1. [知识整理升级实施任务书](implementation/知识整理升级实施任务书.md)
   - 供后续开发 agent 直接执行。
   - 明确本轮目标、数据结构、处理阶段、最小实现范围和验收方式。
2. [用户知识文档需求与工程优化讨论稿](research/用户知识文档需求与工程优化讨论稿.md)
   - 记录需求来源、方案推导、取舍和长期结构建议。
   - 用户材料只作为呈现偏好样本，不作为事实标准答案。

## 项目级交接

- 根目录 [MEMORY.md](../MEMORY.md) 是续接入口。
- `.agents/video-study-project.md` 记录现有功能、验证基线、发行状态和不可破坏的产品约束。
- 根目录 `README.md` 面向使用与开发启动，不承载详细方案。

## 文档约定

- `research/`：问题分析、用户偏好、候选方案和取舍记录。
- `implementation/`：已经形成共识、可以直接实施的任务说明。
- 方案发生变化时，先更新实施任务书，再在交接文档中更新当前优先级。
- 不在文档中复制 `.env`、`QwenAPI.txt` 或任何真实密钥。
