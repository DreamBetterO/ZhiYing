## 最新状态

**项目标识**：用户可见产品名统一为“知影”；Python 导入包与发行包为 `zhiying`，便携可执行文件沿用 `ZhiYing` 工程标识；`video-study` 仅保留为兼容 CLI，`video-study://` 继续作为稳定本地回看协议。

**当前可运行版本基线**：V6.1 正式版本 `1.0.0`，生产使用 23 节点 `Source/Job/Video/Aggregate Graph → NodeExecutor → ArtifactStore/WorkspaceCache` 与 Document v3.1 原生三端渲染。用户已于 2026-08-24 确认正式版本号；最新完整离线验收为 623 项通过（1 项因外部冻结 Workspace 不完整而跳过，5 项预期失败）。

**下一恢复点**：V6.1 已完成 CP61-0～CP61-6，CP61-7 图片证据到 Markdown/Word/PDF 的生产插入链路已补齐；两份高数审阅成品的内容方向仍等待用户确认，因此 CP61-7 继续保持 `in_progress`，不因版本号变更而视为完成。真实工具探针确认 `glm-5.2` 能返回原生工具调用（597 tokens）；下一次真实课程请求、模型/依赖变更、长视频和便携构建仍需分别授权。

**发行状态**：ZhiYing 1.0.0 已按普通使用者视角完成发行收口。`release/` 使用“下载—解压—补齐组件—检查—启动—排错”的简明说明，维护者流程位于 `scripts/release/`。新版核心附件为 `ZhiYing-Core-1.0.0-win-x64.zip`（133710154 bytes，SHA-256 `9d587dc2e4157cf1f509c35e297f3716c372419ed2f660ad2bb76356a18ab86e`），程序烟测、ZIP 完整性、新版随包文档、MIT LICENSE 和清洁度门禁通过；源码进入 `main`，ZIP 与校验文件进入 [`v1.0.0` GitHub Release](https://github.com/DreamBetterO/ZhiYing/releases/tag/v1.0.0)。模型和工具只保留官方链接。
