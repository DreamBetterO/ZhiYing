## 0. 执行摘要

- **目标**：新增「视频链接源获取」能力——粘贴链接 → 爬虫式查找判定（预检）→ yt-dlp 完整下载到本地缓存 → 下载完成「已就绪」提示 → 复用现有 15 步流水线产出 Markdown/Word/PDF + `video-study://` 回看。
- **范围**：`source.acquire` 能力（方式一：`run_compatible_pipeline_from_url`，最小侵入）+ 桌面 UI + 测试规范落地。
- **非目标**：抖音支持（实测不可用，UI 提示暂不支持）；仅音频/音频优先模式（D6：阶段二）；1080P 登录态 UI（D2：不做，保留 `cookies_file` 配置位）；B 站式分段缓存。
- **关键决策**（详见探索方案 §12）：D1 首启合规提示/不内置名单；D2 无登录态、B 站默认 480P；D3 清晰度自动降级链（≤1080P 封顶）；D4 清除缓存保留下载文件；D5 yt-dlp 独立 exe 放 `tools/`；D6 仅音频不进首版；D7 已就绪后手动开始+可选连跑。
