## 编排架构（V6.0）

### 唯一编排器

`GraphRuntime`（`execution/graph_runtime.py`）是唯一生产编排器。LangGraph 负责：

- Graph/子图拓扑（JobGraph → SourceGraph → VideoGraph × N → AggregateGraph → JobFinalize）。
- 节点调度、条件路由和动态任务（视觉任务、章节写作、聚合批次）。
- 同版本运行的暂停、Checkpoint、恢复和取消终态。
- 局部重试、降级路线和 fan-out/fan-in。

`pipeline.py` 保留为兼容门面，只翻译请求并调用 GraphRuntime，不含业务编排。

### NodeExecutor

`NodeExecutor`（`execution/node_executor.py`）是无调度职责的事务执行器，所有产生副作用的节点统一调用：

```
cancel check → resolve/validate inputs → compute fingerprint → cache decide
→ acquire workspace/resource leases → create staging → execute node function
→ validate outcome → atomic artifact commit → cache record → committed event
→ return state delta → LangGraph writes checkpoint
```

强制规则：缓存判定前不初始化昂贵端口；Artifact 提交先于 CacheRecord；副作用幂等。

### Graph 拓扑

```text
JobGraph
├─ SourceGraph
│  ├─ local.resolve
│  └─ url.preflight → url.acquire → source.verify
├─ VideoGraph × N（按队列顺序）
│  ├─ media.probe → audio.extract
│  ├─ transcript.decode → transcript.normalize
│  ├─ frames.candidates → frames.select
│  ├─ knowledge.plan → visual.jobs → visual.evidence → frames.semantics
│  ├─ knowledge.course_ir → knowledge.units → knowledge.selfcheck
│  ├─ editorial.policy → evidence.reconcile
│  ├─ EditorialAgentSubgraph（V6.1）
│  │   blueprint.agent → blueprint.validate → chapter.write[N] → document.assemble
│  │   → preview.render → quality.audit → revision? → patch? → finalize
│  ├─ document.compile → document.validate
│  └─ render.markdown → render.word → render.pdf → render.verify
├─ AggregateGraph（aggregate_mode != none 时）
└─ job.finalize
```

### Graph State 合同

- `JobState`/`VideoState`/`EditorialState` 只保存小型可 JSON 序列化数据和 ArtifactRef 引用。
- **禁止进入 State/Checkpoint**：API Key、RuntimeServices、模型实例、图片/音频/视频二进制、完整 transcript/CourseIR/Document、无界 Prompt/响应/traceback。
- Checkpoint 提供同一次 Job 的执行恢复；WorkspaceCache 提供跨 Job 的计算复用。二者不可互相替代。
- 新 `graph_version` 不迁移旧 Checkpoint；可复用通过校验的 Artifact。

## 编辑 Harness（V6.1）

### EditorialAgentSubgraph

V6.1 在 `knowledge.selfcheck` 与 `document.compile` 之间替换旧伪规划/机械章节链，引入显式 LangGraph 子图：

```text
knowledge.units + visual.evidence + transcript + editorial brief
  → evidence.reconcile        # 证据纠错覆盖层
  → intent.compile            # EditorialPolicy 编译（required/preferred/forbidden）
  → EditorialAgentSubgraph
      ├─ blueprint.agent      # LLM 生成 DocumentBlueprint（可先观察证据）
      ├─ blueprint.validate   # 确定性校验
      ├─ chapter.write[N]     # 分批结构化写作（章指纹缓存）
      ├─ document.assemble     # 组装 Document v3.1
      ├─ preview.render        # 页面预览
      ├─ quality.audit         # 七类质量门审计
      ├─ revision.agent        # 仅失败时触发（最多 1 次默认修订）
      └─ patch.validate/apply  # 白名单 Patch
  → document.compile → document.validate
  → render.markdown.native_v3 → render.word.native_v3 → render.pdf.native_v3
  → render.verify.quality
```

**宏观确定性、微观 Agent 化**：LangGraph 决定拓扑/预算/降级/终态；LLM 只决定文档语义和阶段内工具调用。

### Function Calling 工具集

| 阶段 | 工具 | 模式 |
|------|------|------|
| 规划 | `lookup_evidence` | 只读，返回有界来源段 |
| 规划 | `lookup_visual_facts` | 只读，返回视觉事实（不含图片数据） |
| 规划 | `get_renderer_capabilities` | 只读，返回 v3.1 渲染能力 |
| 规划 | `submit_blueprint` | 写候选 State，后续确定性校验 |
| 写作 | `submit_chapter` | 强制结构化输出 |
| 修订 | `lookup_evidence`（scoped） | 只读，限质量报告涉及范围 |
| 修订 | `get_page_detail` | 只读已有预览报告 |
| 修订 | `submit_patch` | 白名单操作（add/remove/replace/move/set_layout_hint） |
| 修订 | `finish_editing` | 请求最终审计 |

**禁止工具**：`write_file`、`read_arbitrary_path`、`run_shell`、`upload_image`、`mutate_artifact_directly` 等。

### 三级能力降级

| 级别 | 触发条件 | 行为 |
|------|---------|------|
| `tool_native` | 模型稳定返回标准 `tool_calls` | 完整 EditorialAgentSubgraph |
| `structured_only` | 模型不支持工具/连续非法 tool call | 强制结构化输出，无观察循环，仍可用云端正文 |
| `local_deterministic` | 未授权/熔断/所有模型失败/预算耗尽 | 不构造 CloudPort，完整本地语义编译链 |

### 默认调用预算

正常短视频目标 2 次（Blueprint + Writer）；一般问题 3 次；严重 ASR + 修订不超过 4 次。长视频按批次数增加，不开放无界工具轮次。预算比例：规划/观察 20%、正文 65%、修订保留 15%。

## Document v3.1 与原生渲染

### Document v3.1

- `content_blocks` → 组件树（heading/paragraph/list/equation/table/image/container/callout/page_break/source_reference）是唯一新写权威。
- 每个非装饰组件包含稳定 ID、semantic role、source refs、origin、confidence。
- `equation` 保存规范 LaTeX/数学 AST 和证据；Word 原生 OMML。
- `image` 保存 Artifact/visual ID、职责、caption、alt text、来源。
- **生产不再 `v3_to_v2`**；历史 v2/v3 只读兼容。

### 三端原生 Renderer

- **Markdown**：`render_v31.py:render_markdown_v31` 直接遍历 v3.1 组件树。
- **Word**：`scripts/render_docx_v31.mjs` 直接遍历 v3.1，公式生成 OMML（docx 9.7.1 Math）。
- **PDF**：优先由 Word 转换或直接消费同一组件树。
- Renderer 不得自动注入旧业务模板（内容导览/学习目标/课程复习/固定编号等）。

### 质量门

| 门类 | 检查内容 |
|------|---------|
| 意图 | required 全满足、forbidden 命中 0、preferred 给原因 |
| 内容与来源 | 事实组件可追到 source、ASR 错词密度、关键条件/否定/边界完整 |
| 数学 | 确认公式→equation 组件、Word OMML 一致、不足不补造 |
| 视觉 | 图片只在 supportive/required 且证据满足时出现、职责/caption/alt text 齐全 |
| 页面 | 无溢出/异常空白/孤行/不可读图片 |
| 跨格式 | 三端组件覆盖一致、Word OMML 数 = equation 数 |
| 状态 | 阶段 provenance 记录真实来源、degraded 不伪报成功 |

## 证据纠错覆盖层（V6.1）

- 原始 transcript 不可变；纠错写入 `knowledge/evidence-corrections.json`。
- 下游读取 `EffectiveEvidenceView = raw + accepted overlay`。
- 本地先检测：领域高频近音/同音错误、术语多种写法、公式上下文异常汉字等。
- 只把疑点窗口发送给云端，不发送完整 transcript。
- 低置信度不自动改写，标记 `unresolved`。

## 中间件与端口

Step/Node 依赖 `MediaPort`、`SpeechPort`、`VisionPort`、`CloudJsonPort`、`CloudToolPort`（V6.1）、`DocumentPort`、`SourcePort`，具体实现只在 composition root 惰性构造。完全缓存、离线或未授权路径不会初始化无关模型/客户端。

### SourcePort（V5.0）

URL 链接预检与下载：yt-dlp `-J` 预检映射 `SOURCE_*` 错误码；清晰度自动降级链（≤1080P → 720P → 480P → 360P）；ffprobe 时长一致性校验；`WorkspaceCatalog.find_by_url` 下载前缓存命中。配置 `config.yaml source:` 段。

### SpeechPort — ASR 引擎链（V4.2）

faster-whisper（高速）+ Qwen3-ASR（方言）双引擎链回退；V4.2 结构化事件、设备动态适配（CUDA 算子/显存/算力→精度/batch）、热态 RTF 熔断、OOM 有界减半。

### VisionPort — 本地 VLM

Qwen3-VL-2B-Instruct 单视频单会话；V6.0 修复视觉检索消费完整候选池（~600 帧）而非仅全局已选 8 帧的输入合同问题；`none/supportive/required` 三级视觉需求。

### CloudJsonPort / CloudToolPort

`CloudJsonPort`（V4.1）：紧凑 JSON 请求，模型链 `deepseek-v4-flash-0731 → glm-5.2 → kimi-k2.6 → qwen3.7-plus`，共享 `CloudRequestBudget`（默认 5 次/视频）。

`CloudToolPort`（V6.1）：`invoke_turn(messages, tools, tool_choice, stage, budget, cancel_check) → ToolTurn`；复用 OpenAI SDK；LangGraph `ToolNode` 执行只读工具；默认模型首位已切到 `glm-5.2/tool_native`（实测原生工具调用可用）。

### 编辑意图系统

`EditorialPolicy`（V6.1）从用户自然语言编译为 `required/preferred/forbidden` 约束，替代旧 `EditorialBrief`。`LocalIntentCompiler` 提供保守本地回退。`DocumentBlueprint v2` 不含旧 `source_section`，由 LLM 在渲染能力范围内自主规划。

## Artifact 与工作区

每个视频的 Workspace 位于 `workspace/<video_id>/`：

- `manifest.json`（含 `source_url`/`display_title`，URL 源时携带）
- `audio/audio.flac`、`transcript/raw.json`、`transcript/transcript.json`、SRT
- `images/candidates.json`、`images/keyframes.json` 及图片目录
- `knowledge/lesson-plan.json`、`visual-jobs/`、`visual-evidence.json`、`course-ir.json`、`knowledge-units.json`、`selfcheck.json`
- `knowledge/evidence-corrections.json`（V6.1）、`knowledge/editorial-policy.json`（V6.1）、`knowledge/document-blueprint-v2.json`（V6.1）
- `knowledge/chapters/v3.1/*.json`（V6.1）、`knowledge/document-v3.json`（V6.0）、`knowledge/quality-report-v2.json`（V6.1）
- `state/previews/<revision>/page-report.json`（V6.1）
- `state/cache/<step>.json`、`state/pipeline-state.json`、`state/runs/<run_id>.jsonl`

旧 Workspace 通过 `LegacyArtifactAdapter` 单向只读认领；Document v2 只读；历史文件不主动删除。

## 多视频聚合

多视频聚合是 completed items 上的独立 command（AggregateGraph）：每个视频独立执行知识流水线，最终将多个 Document v3 聚合为综合文档；本地聚合始终可用，云端聚合为增强；聚合阶段也共享预算账本；聚合降级时使用本地聚合。

## 版本与缓存

四级版本（V6.0）：

| 版本 | 触发变化 | 失效行为 |
|------|---------|---------|
| `graph_version` | Graph 拓扑/State/Reducer | 新建 thread，验证复用 Artifact |
| `implementation_version` | 节点代码 Bug | 当前节点及下游重算 |
| `contract_version` | Artifact Schema/语义 | Adapter/迁移或重算 |
| `policy_version` | Prompt/模型角色/决策规则 | 仅失效相关模型/决策节点 |

V6.1 新增版本：`tool_contract_version`、`editorial_policy_version`、`blueprint_contract_version`、`document_contract_version=document-v3.1`、`renderer_capability_version`、`prompt_version`、`quality_policy_version`。

## 产品边界

- 仅原生 Windows 桌面与 CLI；不得增加 Web UI、HTTP 服务、端口或 `serve`。
- `.env` 只由授权设置边界处理；不打印、复制、提交秘密。
- `Resource/`、`workspace/`、`output/`、`models/`、`视频/` 是本地数据/产物，不是源码。
- 保持 JSON → Markdown → Word → PDF 和时间戳可追溯。
- 全局单实例互斥（`single_instance.py`）防止多进程同时操作同一工作区。
- LangGraph 是唯一生产编排器；不得恢复旧 `PipelineRunner` 双执行路径。
- 云推理 opt-in；图片云端默认禁止，文本授权不隐式授权图片。
- V6.1 必须保留无需 LLM 的本地确定性完成路径。
- Function Calling 只允许批准的阶段工具、schema、预算和调用上限；不得赋予任意文件/Shell/网络/MCP/图片上传/无限循环权限。
- 云端/工具失败允许自动产出，但状态必须为 `degraded`，并真实记录执行层级、模型链、失败原因和未满足质量项。
- MCP、多 Agent、Web 服务、通用插件平台不进入 V6.1。
- 便携打包默认增量更新：复用 `models/` 与 `tools/`，仅传输非模型、非工具更新；复用前必须校验完整性。
