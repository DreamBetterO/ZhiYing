# 知影 · 视频知识工作台 — 使用说明

> 版本：V6.1 / 产品版本 1.0.0rc1  
> 适用平台：Windows 10/11（原生桌面端）

---

## 1. 产品简介

**知影**是一款原生 Windows 桌面视频整理工具，能够将教学视频自动转化为结构化、可溯源的学习文档。

无论您是在 B 站学习高数、观看技术分享，还是整理培训录像，只需将视频放入知影，即可获得一份带有时间戳回看链接的 Markdown / Word / PDF 学习资料。每个知识点都能一键跳回视频原片段，真正实现"看完视频，带走笔记；阅读笔记，秒回视频"。

---

## 2. 核心功能

| 功能 | 说明 |
|------|------|
| **本地视频整理** | 选择本地 MP4 文件，自动完成语音识别、知识整理、文档生成 |
| **视频链接解析** | 粘贴 B 站等公开视频链接，自动预检、下载并整理（V5.0） |
| **多格式输出** | 同时产出 Markdown、Word、PDF 三份文档 |
| **时间戳溯源** | 文档中每个知识点附带 `video-study://` 链接，点击即可回看原视频 |
| **批量队列** | 支持多视频批量处理，可全选/取消全选、拖动排序 |
| **本地/云端双模式** | 默认本地离线运行；可选云端优化获得更专业的知识整理（V6.1） |
| **智能编辑** | 云端模式下 LLM 自动规划文档结构、写作、质量审计与修订（V6.1） |
| **公式原生渲染** | 数学公式在 Word 中以原生 OMML 渲染，PDF/Markdown 语义一致（V6.1） |
| **视觉证据绑定** | 自动从视频中筛选关键画面，绑定到对应知识点 |
| **缓存恢复** | 中间产物自动缓存，中途退出或清理后重新加入不丢失进度 |
| **精确取消** | 200ms 内即可取消当前任务并清理运行时缓存 |

## 3. 界面概览

### 3.1 主界面

![知影主界面](../screenshot/1.%20%E7%9F%A5%E5%BD%B1%E4%B8%BB%E9%A1%B5.png)

主界面分为四个区域：

- **视频列表区**：显示已添加的本地视频和链接视频，支持多选、排序；
- **工具栏**：添加视频、添加链接、全选、移除、清除缓存等操作；
- **处理偏好区**：设置内容保留量、图文教学级别；
- **操作按钮区**：本地整理、云端优化、聚合、打开产物等。

### 3.2 添加视频链接

![添加视频链接](../screenshot/2.%E8%A7%86%E9%A2%91%E9%93%BE%E6%8E%A5%E8%A7%A3%E6%9E%90%EF%BC%88%E5%93%94%E5%93%A9%E5%93%94%E5%93%A9%E4%B8%BA%E4%BE%8B%EF%BC%89.png)

点击「+ 添加链接」，粘贴视频页面链接（支持 B 站 BV/av 号、直链、HLS 流等），系统将自动预检链接有效性并下载视频。首次使用时会提示合规说明。当前暂不支持抖音链接。

下载完成后视频显示「已就绪」状态，勾选后即可开始整理。

### 3.3 模型与云端设置

![模型配置](../screenshot/3.%20%E6%A8%A1%E5%9E%8B%E9%85%8D%E7%BD%AE.png)

点击「模型与云端设置」可配置：

- **API URL / API Key**：云端优化所需的接口地址与密钥；
- **云端模型链**：默认使用 glm-5.2 → deepseek-v4-flash-0731 → kimi-k2.6 → qwen3.7-plus；
- **本地语音模型**：faster-whisper（高速，默认）或 Qwen3-ASR（方言识别）；
- 可勾选「记住 API Key」将密钥保存到本地 `.env` 文件。

### 3.4 云端优化授权与编辑偏好

![云端优化授权](../screenshot/4.%E7%94%9F%E6%88%90%E7%9A%84%E6%96%87%E6%A1%A3%E5%81%8F%E5%A5%BD%E6%8F%90%E7%A4%BA%E8%AF%8D.png)

启用云端优化时，系统会在发送数据前展示：

- 上传内容摘要（仅发送压缩后的转写文本，不含视频/截图/密钥）；
- 实际调用的端点、模型链和预算；
- 本次整理要求输入框：可用自然语言描述偏好，例如"这是考研高数知识点，整理时侧重概念的讲解"。

确认授权后才会发起云端请求，每次整理独立授权。

### 3.5 运行中状态

![运行中](../screenshot/5.%E8%BF%90%E8%A1%8C%E4%B8%AD%EF%BC%88%E6%9C%AC%E5%9C%B0GPU%EF%BC%89.png)

处理过程中，列表显示每条视频的：

- **状态**：等待中 / 处理中 / 已就绪 / 已完成 / 已取消；
- **当前步骤**：如"语音识别"、"知识整理"、"文档生成"等；
- **进度**：百分比进度条；
- **已用时间**：当前步骤耗时；
- **Token 统计**（云端模式）：输入/输出/总 Token 数。

底部状态栏显示全局任务进度与 ETA 估算。GPU 占用情况可在任务管理器中查看。

### 3.6 取消任务

![取消任务](../screenshot/%E5%8A%9F%E8%83%BD%EF%BC%9A%E5%8F%96%E6%B6%88%E5%BD%93%E5%89%8D%E5%B7%A5%E4%BD%9C%E5%B9%B6%E6%B8%85%E9%99%A4%E7%BC%93%E5%AD%98%EF%BC%88200ms%E5%86%85%E5%8D%B3%E5%8F%AF%E5%8F%96%E6%B6%88%E5%B9%B6%E6%B8%85%E9%99%A4%E8%BF%90%E8%A1%8C%E6%97%B6%E7%9A%84%E7%BC%93%E5%AD%98%EF%BC%89.png)

处理过程中可随时点击「取消当前任务」，系统将在 200ms 内终止运行并清理运行时缓存，状态回退为"已取消"。

### 3.7 清理缓存

![清除缓存](../screenshot/%E5%8A%9F%E8%83%BD%EF%BC%9A%E6%B8%85%E9%99%A4%E5%85%A8%E9%83%A8%E7%BC%93%E5%AD%98.png)

- **清除所选缓存**：仅清理选中视频的中间产物，保留原视频和下载文件；
- **清理全部缓存**：二次确认后清空所有工作区中间文件，最终文档和原视频不受影响。

### 3.8 文档产出效果

![产出效果](../screenshot/6.%E4%BA%A7%E5%87%BA%E6%95%88%E6%9E%9C.png)

生成的 Word 文档包含：

- 结构化章节标题与正文；
- 原生渲染的数学公式（OMML）；
- **回看来源**链接（如 `▶ 回看来源 ··· 00:00`），点击后自动调用本地播放器定位到原视频对应时间；
- 关键画面截图绑定到对应知识点。

## 4. 快速开始

### 4.1 启动程序

方式一：双击根目录下的 `启动桌面版.cmd`。  
方式二：命令行启动：

```powershell
.venv\Scripts\video-study.exe desktop --config config.yaml
```

### 4.2 整理本地视频

1. 将 MP4 文件放入 `Resource/` 目录，或点击「+ 添加视频」选择文件；
2. 勾选要处理的视频；
3. 选择内容保留量（精简/推荐/丰富）和图文教学级别；
4. 点击「本地整理」，等待处理完成；
5. 点击「打开产物目录」查看 Markdown / Word / PDF 文件。

### 4.3 整理视频链接

1. 点击「+ 添加链接」，粘贴视频 URL；
2. 点击「解析并下载」，等待预检和下载完成（状态变为「已就绪」）；
3. 勾选已就绪的视频，点击「本地整理」或「云端优化」；
4. 云端优化需确认授权对话框后才开始。

### 4.4 多视频聚合

将多个视频整理完成后，勾选已完成的视频，点击「本地聚合」或「云端聚合」，系统会将多份文档合并为一份综合学习资料，每个知识点仍保留各自的视频回看链接。

## 5. 处理偏好说明

| 偏好项 | 选项 | 说明 |
|--------|------|------|
| **内容保留量** | 精简 | 复习提纲，只保留最关键定义、规则和结论 |
| | 推荐 | 标准课程笔记，保留必要解释、步骤、案例（默认） |
| | 丰富 | 完整课程讲义，尽量保留推导过程、多案例、边界条件 |
| **图文教学** | 自动 / 精简 / 均衡 / 增强 | 控制从视频中提取并嵌入文档的关键画面数量与密度 |

内容详略与视觉证据预算相互独立，可自由组合。

## 6. 两种整理模式对比

| 维度 | 本地整理 | 云端优化 |
|------|----------|----------|
| 默认状态 | 开启 | 关闭 |
| 费用 | 免费 | 消耗云端 Token |
| 隐私 | 视频不上传，完全本地 | 仅发送压缩转写文本，不含视频/截图 |
| 质量 | 启发式筛选，保证可溯源 | LLM 规划+写作+修订，更专业完整 |
| 公式处理 | 本地渲染 | 原生 OMML 数学公式 |
| 授权 | 无需 | 每次需用户明确授权 |
| 失败降级 | 直接生成离线文档 | 三级降级 → 最终本地确定性链 |

## 7. 来源回看说明

文档中的来源链接使用 `video-study://` 本地协议。桌面程序启动时会自动为当前 Windows 用户注册该协议。

- 在 Word 或 PDF 中点击「回看来源」链接；
- 系统直接调用本地播放器（优先 `ffplay -ss` 精确定位）；
- 无需启动 Web 服务或打开浏览器网页。

> 若未安装 ffplay，将回退到系统默认播放器，此时可能需要手动拖动进度条定位。

| 目录/文件 | 说明 |
|-----------|------|
| `Resource/` | 放置本地 MP4 视频 |

| `课程资料整理偏好.md` | （可选）用自然语言描述整理偏好，云端优化时自动加载 |

## 9. 常见问题

**Q：清理缓存会删除我的视频吗？**  
A：不会。清除缓存仅删除 `workspace/` 中的中间产物，保留 `Resource/` 中的原视频和 `视频/` 中的下载文件。

**Q：云端优化安全吗？**  
A：云端模式下仅发送压缩后的转写文本（CourseIR 投影），不发送视频文件、截图或密钥。每次发送前都会展示内容摘要并要求您确认授权。

**Q：支持哪些视频链接？**  
A：目前支持 B 站（无登录默认 480P）、W3C trailer、test-videos.co.uk、Mux HLS 等公开视频。暂不支持抖音（签名限制）。

**Q：处理过程中可以关闭软件吗？**  
A：建议先点击「取消当前任务」。下次启动后重新加入同一视频，系统会自动复用已完成的中间缓存，从中断处继续。
