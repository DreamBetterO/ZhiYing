# 知影使用说明

> 适用版本：V6.1 / 1.0.0 · Windows 10/11 桌面端

知影把本地教学视频或公开视频链接整理成带来源时间戳的 Markdown、Word 和 PDF。你可以阅读整理后的笔记，也可以从文档中的“回看来源”直接跳回原视频对应位置。

如果你只想尽快用起来，阅读“[第一次使用](#第一次使用)”即可。

## 你会得到什么

一次整理通常会生成：

- 一份适合快速查看和二次编辑的 Markdown；
- 一份带标题、图片和原生数学公式的 Word；
- 一份适合阅读和分享的 PDF；
- 每个重要内容对应的原视频时间链接；
- 可复用的转写、关键帧和知识整理缓存。

知影不是简单地把字幕复制进文档。它会结合转写、时间戳和关键画面，组织章节、解释、步骤、案例与来源。

## 第一次使用

### 1. 启动知影

双击项目根目录的 `启动桌面版.cmd`。

开发环境也可从命令行启动：

```powershell
.venv\Scripts\zhiying.exe desktop --config config.yaml
```

### 2. 添加视频

你可以选择一种方式：

- **本地视频**：点击“＋ 添加本地视频”，选择 MP4；
- **视频链接**：点击“＋ 添加视频链接”，粘贴链接，等待状态变为“已就绪”。

链接视频会先下载到本地，之后与本地文件走同一条整理流程。当前并非所有网站都能稳定解析；遇到失败时，以界面给出的错误说明为准。

### 3. 选择整理偏好

| 设置 | 适合场景 |
|---|---|
| 精简 | 临考复习、快速回顾 |
| 推荐 | 日常学习笔记，默认选择 |
| 丰富 | 完整讲义、保留更多推导和案例 |
| 图文自动 | 由系统按内容决定是否插图 |
| 图文精简 / 均衡 / 增强 | 逐步增加关键画面的使用密度 |

内容详略和图片密度互不绑定，可以自由组合。

### 4. 开始整理

- 点击“生成本地文档”：完全本地处理，不调用云端接口；
- 点击“使用云端优化”：先查看发送内容、模型和预算，再明确授权本次请求。

处理过程中可以看到当前阶段、进度、耗时和预计剩余时间。云端模式还会显示 Token 用量。

### 5. 查看结果

任务完成后点击“打开输出目录”。最终文件位于 `output/`，中间结果位于 `workspace/`。

## 本地模式与云端模式

| 对比项 | 本地模式 | 云端模式 |
|---|---|---|
| 默认状态 | 可直接使用 | 默认关闭 |
| 网络与费用 | 不需要云端调用 | 消耗云端 Token |
| 发送内容 | 不发送 | 发送压缩后的文字证据，不发送视频、截图或密钥 |
| 内容组织 | 本地确定性策略 | 模型参与结构规划、写作和有限修订 |
| 失败时 | 继续生成本地文档 | 自动退回结构化云端或本地链，并标明降级原因 |
| 授权 | 无需 | 每次单独确认 |

无论使用哪种模式，正文都会先整理成统一的内容结构，再从中生成 Markdown、Word 和 PDF。这样三种格式共享同一套正文、公式、图片和来源。

## 多视频合并

多个视频分别整理完成后，勾选已完成项目，再选择本地合并或云端优化合并。综合文档会按视频组织内容，并保留各自的来源链接。

合并不会改变原视频的单独产物。

## 回看原视频

文档中的来源使用 `video-study://` 本地协议。点击链接后，系统会调用本地播放器并尽量定位到对应时间。

- 该链接不会打开网页，也不会启动本地 Web 服务；
- 优先使用 `ffplay` 精确定位；
- 没有 `ffplay` 时会调用系统默认播放器，可能需要手动拖动进度条。

## 缓存、取消与文件位置

| 位置 | 内容 | 说明 |
|---|---|---|
| `Resource/` | 本地输入视频 | 清理工作区时保留 |
| `视频/` | 链接下载的视频 | 清理工作区时保留 |
| `workspace/` | 转写、关键帧、知识结构等可恢复中间结果 | 可通过界面清理 |
| `output/` | Markdown、Word、PDF | 可重新生成 |
| `models/` | 本地模型 | 不要随意删除或覆盖 |

取消任务只停止当前运行，不会删除源视频。重新加入同一视频时，系统会优先复用已经校验通过的中间结果。

## 常见问题

### 清理缓存会删除原视频吗？

不会。工作区清理保留 `Resource/` 中的本地视频和 `视频/` 中的下载文件。界面会明确提示将要删除的范围。

### 云端优化会上传视频或截图吗？

不会。当前文本授权只覆盖压缩后的文字证据；视频和截图不上传，图片授权也不能由文本授权隐式获得。

### 为什么文档里的某段内容比较简略？

通常是原视频证据不足、转写置信度低，或云端能力降级。知影会优先避免把不确定内容写成确定结论。可查看任务的降级状态和来源链接。

### 关闭软件后还能继续吗？

建议先取消当前任务再退出。下次处理同一视频时，已提交并校验通过的步骤会从缓存恢复。

### 为什么链接解析失败？

网站策略、登录要求或网络状态都可能变化。不要把某个站点的历史成功案例理解为永久兼容承诺，以界面当前诊断为准。
