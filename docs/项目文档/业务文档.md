> 版本对应：V6.1 / 产品版本 1.0.0rc1
> 最后更新：2026-08-20
> 深入技术细节请参阅 [`架构详解`](架构详解.md)

## 1. 产品概述

**知影**是一款原生 Windows 桌面视频整理工具，将教学视频转化为可溯源的学习文档。

支持两种视频来源：本地文件（MP4）和视频链接（V5.0）。粘贴链接后自动预检、下载到本地缓存，复用同一条整理链路。

核心处理链路：

```
本地 MP4 / 视频链接 → [链接预检+下载] → 音频/关键帧 → 带时间戳转写 JSON
    → 知识整理 → 编辑 Harness（文档规划+章节写作+质量审计）
    → Document v3.1 → Markdown → Word → PDF
```

V6.0 将生产编排器迁移到 LangGraph，实现全链路 Graph 编排。V6.1 引入受控 Function Calling 编辑 Harness，让 LLM 在证据和渲染能力范围内真正拥有文档设计、主动观察和局部修订权，同时保留完整可运行的本地确定性完成路径。

视频始终使用本地绝对路径，不上传、不复制。云端整理默认关闭，启用前需展示发送内容、模型和预算并获得用户明确授权。文档中的来源链接使用 `video-study://` 本地协议，点击后调用本地播放器定位，不启动 Web 服务。

## 2. 核心价值

| 价值 | 说明 |
|------|------|
| **可溯源** | 每个知识点都带有原视频时间戳链接，点击即可回看原始讲解片段 |
| **离线优先** | 语音识别、关键帧提取、知识整理均可完全离线运行，不依赖云端 |
| **结构化** | 转写不是简单复制，而是按知识类型专业化整理为章节、知识点、步骤、规则、案例等结构 |
| **多格式输出** | 同时生成 Markdown、Word、PDF 三种格式，满足不同阅读场景 |
| **视觉证据** | 从视频关键帧中筛选并绑定真实画面到对应知识点，非随意配图 |
| **链接即整理** | 粘贴视频链接即可完成下载和整理，无需手动下载视频文件（V5.0） |
| **原生公式** | 数学公式以 Word 原生 OMML 渲染，Markdown/PDF 语义一致（V6.1） |
| **智能编辑** | LLM 可主动查询证据、规划文档结构、局部修订质量问题（V6.1） |
| **降级透明** | 云端/工具失败时自动降级，明确告知用户实际使用的能力和原因（V6.1） |
| **隐私安全** | 视频不上传，云端默认关闭，密钥不提交，图片云端默认禁止 |

## 3. 用户场景

### 3.1 典型用户

- **学生/自学者**：观看教学视频后需要系统化复习资料
- **培训讲师**：将授课录像转化为可分发讲义
- **知识管理者**：整理团队会议录像或技术分享视频

### 3.2 典型工作流

**方式一：本地文件**

1. 用户将 MP4 视频放入 `Resource/` 目录或通过桌面端文件选择器添加
2. 启动桌面端，选择视频加入处理队列
3. 系统自动执行：音频提取 → 语音识别 → 关键帧提取 → 知识整理 → 文档生成
4. 用户在 `output/` 目录获得 Markdown、Word、PDF 三份文档
5. 阅读文档时点击知识点旁的来源链接，本地播放器自动定位到原视频对应时间

**方式二：视频链接（V5.0）**

1. 用户在桌面端点击「＋ 添加链接」，粘贴视频链接
2. 系统自动预检链接（判定有效性、清晰度、是否需要登录等）
3. 预检通过后自动下载到本地缓存（清晰度自动降级，≤1080P 封顶）
4. 下载完成后显示「已就绪」提示，用户手动开始整理（可选「下载并立即整理」连跑）
5. 系统复用同一条处理链路，产出 Markdown、Word、PDF + `video-study://` 回看

### 3.3 多视频聚合

用户可将多个视频的产物聚合为一份综合文档，每个知识点保留各自视频的来源回看链接，按视频生成多个逻辑章节。云端聚合失败时自动降级到本地聚合。

## 4. 处理流程（业务视角）

### 4.1 主流水线阶段

| 阶段 | 业务名称 | 说明 | 缓存策略 |
|------|----------|------|----------|
| 0 | 源获取（V5.0） | 粘贴链接 → 预检 → 下载到本地缓存 → 时长校验 | URL 缓存命中则跳过下载 |
| 1 | 音频提取 | 从 MP4 提取 16 kHz 单声道 FLAC 音频 | 文件存在则跳过 |
| 2 | 语音识别 (ASR) | 将音频转为带时间戳的文本段；支持引擎链降级（V4.2） | 转写 JSON 存在则跳过 |
| 3 | 关键帧提取 | 从视频按间隔采样候选帧，按场景聚类筛选 | 候选帧存在且配置未变则复用 |
| 4 | 知识整理 | 将转写文本结构化为章节和知识点 | document 存在且输入未变则跳过 |
| 5 | 编辑 Harness（V6.1） | LLM 规划文档蓝图 → 章节写作 → 质量审计 → 局部修订 | 按 Blueprint/Chapter/Patch 独立缓存 |
| 6 | 文档生成 | 渲染为 Markdown、Word、PDF（原生 v3.1 组件树） | 每次重新生成 |

### 4.2 两种整理模式

#### 离线模式（默认，V6.1 本地确定性链）

- 完全在本地运行，不调用云端 API
- V6.1 本地链不是旧模板 fallback，而是完整语义编译器：`LocalIntentCompiler → LocalEvidenceReconcile → LocalBlueprintPolicy → LocalDocumentComposer → LocalDocumentAudit → LocalDeterministicRepair → 原生 v3.1 渲染`
- 本地无法可靠精炼时不把大段口语伪装成规则/步骤，生成简洁可追踪的降级资料
- 公式证据不足时不补造，标记不确定

#### 云端模式（需用户授权）

- V6.1 引入受控 Function Calling：LLM 可主动查询证据、规划文档结构、局部修订
- 模型链：`glm-5.2`（默认，tool_native）→ `deepseek-v4-flash-0731` → `kimi-k2.6` → `qwen3.7-plus`
- 正常短视频默认 2 次云调用（Blueprint + Writer）；异常时按问题触发观察/修订
- Function Calling 不可用时先降级结构化云端，再降级本地确定性链
- 降级产物允许自动输出，但必须标记 `degraded` 和实际能力，不得伪报「智能整理」成功
- 支持「精简 / 推荐 / 丰富」三种详略档位
- 编辑意图系统：用户通过自然语言表达偏好，系统编译为 `required/preferred/forbidden` 约束

### 4.3 视觉教学与证据系统

- **视觉教学级别**：自动 / 精简 / 均衡 / 增强
- **视觉需求分级**（V6.0）：`none`（不创建视觉任务）/ `supportive`（辅助）/ `required`（可密集采样）
- **视觉证据流程**：规划阶段生成像素可回答的视觉问题 → 从完整候选池（~600 帧）召回 → 本地 VLM 逐任务核验 → 仲裁去重 → 绑定到知识点
- **V6.0 修复**：视觉检索消费完整候选池而非仅全局已选 8 帧

## 6. 桌面端使用指南

### 6.1 启动方式

```powershell
# 方式一：命令行
.venv\Scripts\video-study.exe desktop --config config.yaml

# 方式二：双击启动脚本
启动桌面版.cmd
```

### 6.2 界面布局

- **视频列表区**：显示 `Resource/` 目录中的 MP4 文件 + 链接下载的视频，可全选/取消全选；新增「来源」列区分本地文件和链接下载（V5.0）
- **添加按钮区**：「添加文件」+「＋ 添加链接」（V5.0）
- **处理控制区**：ASR 引擎选择（下拉单选）、内容详略、视觉教学级别、云端优化开关
- **进度区**：进度条 + 2 行固定高度滚动日志（V5.1：垂直滚动条 + 追加式记录，保留最近 200 行）
- **结果区**：处理完成后显示产物路径，可直接打开；Token 列完整可见（V5.1：窗口宽度 1040+）

### 6.3 典型操作

1. **添加视频**：
   - 本地文件：将 MP4 放入 `Resource/` 目录，或通过文件选择器添加
   - 视频链接（V5.0）：点击「＋ 添加链接」，粘贴链接 → 系统预检 → 下载 → 「已就绪」提示
2. **选择引擎**：默认 faster-whisper（高速），可选 Qwen3-ASR（方言）（需模型已下载）
3. **设置详略**：选择精简/推荐/丰富
4. **开始处理**：点击"开始处理"，系统自动执行全部阶段；链接源下载完成后也可手动开始
5. **查看产物**：处理完成后点击"打开产物目录"
6. **回看来源**：在 Word/PDF 中点击来源时间链接，播放器自动定位

### 6.4 视频链接说明（V5.0）

- 首次使用链接功能时展示合规提示，不内置站点名单
- 支持的站点：B 站（无登录默认 480P）、W3C trailer、test-videos.co.uk、Mux HLS 等公开视频
- 暂不支持：抖音（a_bogus 签名限制），UI 明确提示
- 清晰度自动降级：≤1080P 封顶 → 720P → 480P → 360P
- 登录态不做 UI（新版 Chrome/Edge v20 加密限制），保留 `cookies_file` 配置位
- 清除缓存保留下载文件——仅清除 Workspace 中间产物

### 6.5 云端优化

- 默认关闭
- 启用时需输入 API Key（可选"记住密钥"保存到 `.env`）
- 发送前展示：发送内容摘要、模型链、调用预算
- 全程受 `max_calls_per_video` 控制（默认 5 次/视频）
- 可随时取消
- V6.1：降级状态透明，显示实际模型链和降级原因

## 8. 文档产物说明

### 8.1 文档结构（V6.1 Document v3.1）

V6.1 的文档不再使用固定模板，而是由 LLM 或本地策略在渲染能力范围内自主规划。组件类型包括：

```
heading（标题）
├── paragraph（正文段落）
├── list（列表）
├── equation（公式，Word OMML 原生）
├── table（表格）
├── image（图片，含职责/caption/alt text）
├── container（容器）
├── callout（提示框）
├── page_break（分页）
└── source_reference（来源链接 — video-study:// 回看）
```

旧固定栏目（内容导览/学习目标/课程复习/固定编号/看图重点话术）不再自动注入，由编辑策略决定是否存在。

### 8.2 内容详略档位

| 档位 | 定位 | 知识点密度 | 细节保留 |
|------|------|-----------|----------|
| 精简 | 复习提纲 | 每章 1–3 个 | 只保留最关键定义、规则和结论 |
| 推荐 | 标准课程笔记 | 每章 2–6 个 | 保留必要解释、步骤、案例、适用条件、易错点 |
| 丰富 | 完整课程讲义 | 每章 2–6 个 | 尽量保留推导过程、多案例、边界条件、易错点和复习提示 |

### 8.3 Schema 版本

- **Schema v1/v2**：旧版文档格式，只读兼容
- **Schema v3 / Document v3.1**（V6.0/V6.1 默认）：组件树为正文唯一事实源，Markdown/Word/PDF 原生消费

### 8.4 编辑偏好（V6.1）

用户可在项目根目录创建 `课程资料整理偏好.md` 文件，用自然语言描述整理偏好。系统会：

1. 编译为 `EditorialPolicy`（required/preferred/forbidden 约束）
2. LLM 在规划阶段消费策略，生成 `DocumentBlueprint`
3. 蓝图贯穿章节写作和质量审计
4. 策略版本和意图 hash 记录在产物中，确保可审计
5. 复杂意图本地不能完全解析时标记 `partially_satisfied`，不伪装完全遵循

## 9. 安全与隐私

### 9.1 数据安全

- 视频文件始终使用本地绝对路径，不上传、不复制
- 视频链接下载到本地缓存后，后续处理与本地文件完全一致（V5.0）
- 云端模式仅发送压缩后的转写文本（CourseIR 投影），不含视频或截图
- V6.1 Function Calling 只发送有界来源段和视觉事实摘要，不发送完整 transcript
- 图片云端默认禁止；Function Calling 不得成为隐式图片上传通道（V6.1）
- 删除缓存与产物不会删除源 MP4 和下载的视频文件

### 9.2 密钥安全

- API Key 仅在用户启用"记住密钥"后保存到 `.env`
- `.env` 已被 `.gitignore` 忽略
- Graph State/Checkpoint/事件/缓存不保存密钥（V6.0）
- 禁止在代码、日志或文档中输出密钥

### 9.3 云端授权

- 云端推理默认关闭
- 真实云调用前必须逐次说明：发送数据、端点、模型链和预算
- 获得用户明确授权后才发起请求
- 图片授权与文本授权分离（V6.0）
- 降级产物必须标记实际能力，不得伪报成功（V6.1）

### 9.4 本地 VLM 安全

- 本地 VLM 为 `auto` 模式：仅在本机模型、运行时和 CUDA 预检通过时启用
- 不上传截图、不消耗云端 token
- 缺能力时明确降级，不静默失败

### 9.5 视频链接安全（V5.0）

- 链接预检使用 yt-dlp 独立 exe，不内嵌浏览器引擎
- 下载文件大小限制（默认 2GB），超限拒绝下载
- 下载后 ffprobe 时长一致性校验
- 首启合规提示，不内置站点名单
- 不自动读取浏览器 cookie

### 9.6 Function Calling 安全（V6.1）

- 工具集分阶段绑定，不得每轮发送全部 schema
- 禁止任意文件/Shell/网络/图片上传工具
- 同一调用只允许一个修改型工具
