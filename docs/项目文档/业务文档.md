# 知影业务说明

> 适用版本：V6.1 / 1.0.0

这份文档回答四个问题：知影为谁服务、解决什么问题、提供什么能力，以及明确不做什么。操作方式见[软件介绍](软件介绍.md)，技术实现见[架构详解](架构详解.md)。

## 一句话定位

知影是一款离线优先的 Windows 视频知识整理工具：它把本地教学视频或公开视频链接转成结构化、可回看来源的学习文档。

## 用户面对的问题

视频适合讲解，却不适合快速检索和复习：

- 重要内容散落在时间轴中，重看成本高；
- 自动字幕保留口语，却缺少章节和知识结构；
- 截图与文字容易脱节，不知道画面究竟证明什么；
- 手工整理公式、步骤和来源耗时；
- 使用云端工具时，用户往往不清楚发送了什么、花费多少、失败后发生了什么。

知影的目标不是替用户“看完”视频，而是降低从视频回到证据、从证据整理成资料的成本。

## 目标用户与场景

| 用户 | 典型场景 | 期望结果 |
|---|---|---|
| 学生与自学者 | 课程、考研、技术教程 | 可复习、可定位原讲解的笔记 |
| 教师与培训者 | 课程录像、培训回放 | 可继续编辑和分发的讲义 |
| 团队知识整理者 | 技术分享、内部培训 | 按主题组织并保留来源的资料 |

知影最适合信息密度较高、需要反复回看的讲解型视频。它不是通用剪辑工具，也不替代播放器或课程平台。

## 核心价值

### 1. 每个结论都尽量回到来源

重要内容带有视频时间戳。读者遇到疑问时，可以从文档直接回看原讲解，而不是把摘要当成不可核验的答案。

### 2. 默认不依赖云端

语音识别、关键帧、内容组织和三种文档输出都有本地完成路径。没有云端授权或云端失败时，任务仍然能够产出文档。

### 3. 输出可继续使用

同一次整理生成 Markdown、Word 和 PDF。Word 支持原生数学公式；不同格式由同一份结构化内容生成，减少三份文件互相矛盾。

### 4. 图片是证据，不是装饰

系统从视频候选帧中寻找能回答具体问题的画面，再把它绑定到对应内容。找不到合格证据时可以不插图。

### 5. 智能能力受约束、可降级

云端模型只能在限定阶段查询证据、提交结构化内容和进行局部修订。失败时系统记录真实能力层级与原因，不把本地降级伪装成云端成功。

## 用户工作流

```text
添加本地视频或链接
        ↓
选择详略与图文偏好
        ↓
选择本地整理，或确认一次云端授权
        ↓
等待转写、证据整理和文档生成
        ↓
阅读 Markdown / Word / PDF
        ↓
从来源链接回看原视频
```

多个视频完成后，还可以合并为一份综合文档；每段内容继续保留各自的视频来源。

## 产品能力

### 输入

- 本地 MP4；
- 可被当前下载适配器预检和获取的公开视频链接；
- 用户选择的内容详略、图文密度和自然语言整理要求。

链接站点兼容性会受对方策略、登录要求和网络环境影响，因此不把历史可用站点写成永久承诺。

### 处理

- 视频探测和音频提取；
- 带时间戳的语音识别与规范化；
- 候选帧采样、视觉证据筛选；
- 章节、知识点、步骤、案例和来源的结构化整理；
- 可选的云端规划、写作和有限修订；
- 缓存、取消、恢复、进度与降级记录。

### 输出

| 产物 | 主要用途 |
|---|---|
| Markdown | 快速查看、版本管理、二次加工 |
| Word | 编辑、打印、公式与图文排版 |
| PDF | 稳定阅读与分享 |
| 来源链接 | 从文档回到原视频时间点 |
| 运行与质量记录 | 解释实际走过的能力链和降级原因 |

## 本地与云端的业务差异

| 维度 | 本地整理 | 云端优化 |
|---|---|---|
| 是否默认可用 | 是 | 否，需逐次授权 |
| 数据外发 | 无 | 仅批准的压缩文字证据 |
| 内容组织 | 确定性本地策略 | 模型参与蓝图、正文和有限修订 |
| 成本 | 无云端 Token | 受单视频预算限制 |
| 失败处理 | 继续本地完成 | 结构化云端降级，再退回本地 |
| 对用户的说明 | 本地完成 | 显示实际模型、能力层级和降级原因 |

云端文本授权不等于图片授权。当前默认不向云端发送视频或截图。

## 关键业务规则

### 来源真实性优先

- 不足以支持的公式、结论或图片不应被补造；
- 原始转写保留不变，纠错以覆盖层记录；
- 重要内容应能追到时间戳或视觉证据；
- 低置信度内容宁可保守表达，也不伪装为确定事实。

### 用户知情优先

- 云端默认关闭；
- 每次真实云调用前展示数据、端点、模型和预算；
- 失败和降级必须可见；
- 清理操作明确区分源视频、下载文件、中间缓存和最终产物。

### 可恢复优先

每个主要阶段独立保存结果。中断、取消或重新启动后，已提交且校验通过的结果可以复用，避免重复耗时和云端成本。

## 产品边界

知影当前明确保持以下边界：

- 原生 Windows 桌面应用，不提供 Web UI、本地 HTTP 服务或端口监听；
- `video-study://` 只调用本地播放器，不打开网页；
- 视频始终本地处理，不因启用文本云端优化而上传；
- 不自动读取浏览器 Cookie，不绕过站点访问控制；
- 不承诺所有链接站点始终可用；
- 不在证据不足时编造公式、图像含义或确定结论；
- 不把任意文件、Shell、网络或无限循环权限交给模型；
- 历史工作区只读兼容，不主动删除。

## 成功标准

一份好的知影片段整理至少应满足：

1. 用户可以顺畅阅读，而不是看到字幕堆砌；
2. 关键内容能回到原视频核验；
3. 图片、公式和结论有足够证据；
4. Markdown、Word、PDF 的核心语义一致；
5. 云端未授权或失败时仍能完成；
6. 用户能够知道任务是否降级，以及为什么降级。
