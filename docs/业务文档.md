# 知影 · 视频知识工作台 — 业务文档

> 版本对应：V4.1 / 产品版本 0.4.1
> 最后更新：2026-08-14
> 深入技术细节请参阅 [`架构详解`](架构详解.md)

---

## 1. 产品概述

**知影**是一款原生 Windows 桌面视频整理工具，将教学视频转化为可溯源的学习文档。

核心处理链路：

```
MP4 → 音频/关键帧 → 带时间戳转写 JSON → 知识 JSON (Course IR)
    → Markdown → Word → PDF
```

视频始终使用本地绝对路径，不上传、不复制。云端整理默认关闭，启用前需展示发送内容、模型和预算并获得用户明确授权。文档中的来源链接使用 `video-study://` 本地协议，点击后调用本地播放器定位，不启动 Web 服务。

---

## 2. 核心价值

| 价值 | 说明 |
|------|------|
| **可溯源** | 每个知识点都带有原视频时间戳链接，点击即可回看原始讲解片段 |
| **离线优先** | 语音识别、关键帧提取、知识整理均可完全离线运行，不依赖云端 |
| **结构化** | 转写不是简单复制，而是按知识类型专业化整理为章节、知识点、步骤、规则、案例等结构 |
| **多格式输出** | 同时生成 Markdown、Word、PDF 三种格式，满足不同阅读场景 |
| **视觉证据** | 从视频关键帧中筛选并绑定真实画面到对应知识点，非随意配图 |
| **隐私安全** | 视频不上传，云端默认关闭，密钥不提交 |

## 3. 用户场景

### 3.1 典型用户

- **学生/自学者**：观看教学视频后需要系统化复习资料
- **培训讲师**：将授课录像转化为可分发讲义
- **知识管理者**：整理团队会议录像或技术分享视频

### 3.2 典型工作流

1. 用户将 MP4 视频放入 `Resource/` 目录或通过桌面端添加
2. 启动桌面端，选择视频加入处理队列
3. 系统自动执行：音频提取 → 语音识别 → 关键帧提取 → 知识整理 → 文档生成
4. 用户在 `output/` 目录获得 Markdown、Word、PDF 三份文档
5. 阅读文档时点击知识点旁的来源链接，本地播放器自动定位到原视频对应时间

### 3.3 多视频聚合

用户可将多个视频的产物聚合为一份综合文档，每个知识点保留各自视频的来源回看链接，按视频生成多个逻辑章节。云端聚合失败时自动降级到本地聚合（V4.1）。

## 4. 处理流程（业务视角）

### 4.1 主流水线阶段

| 阶段 | 业务名称 | 说明 | 缓存策略 |
|------|----------|------|----------|
| 1 | 音频提取 | 从 MP4 提取 16 kHz 单声道 FLAC 音频 | 文件存在则跳过 |
| 2 | 语音识别 (ASR) | 将音频转为带时间戳的文本段 | 转写 JSON 存在则跳过 |
| 3 | 关键帧提取 | 从视频按间隔采样候选帧，按场景聚类筛选 | 候选帧存在且配置未变则复用 |
| 4 | 知识整理 | 将转写文本结构化为章节和知识点 | document.json 存在且输入未变则跳过 |
| 5 | 文档生成 | 渲染为 Markdown、Word、PDF | 每次重新生成 |

### 4.2 两种整理模式

#### 离线模式（默认）

- 完全在本地运行，不调用云端 API
- 使用启发式算法对转写文本进行分章、信息量评分、知识点筛选
- 支持 Course IR 去重：exact 去重 + 可证明 containment 自动去重，near-duplicate 仅报告不删除
- 产物为"离线提取"模式文档

#### 云端模式（需用户授权）

- 将压缩后的 CourseIR 投影发送给云端大语言模型
- 模型链依次故障转移：`deepseek-v4-flash-0731` → `glm-5.2` → `kimi-k2.6` → `qwen3.7-plus`
- 云端模型按写作计划逐项整理，生成专业讲义
- 支持"精简 / 推荐 / 丰富"三种详略档位
- 全程受 `max_calls_per_video` 预算控制（默认 5 次/视频），所有阶段共享请求账本
- 载荷按 token 上限自动分批，截断不重试以节省预算
- 构造或预算失败时停止发送并保留本地产物，不回退旧大 prompt
- V4.1 新增编辑意图：用户可通过 `课程资料整理偏好.md` 表达整理偏好，系统生成编辑决策注入规划和写作

### 4.3 视觉教学与证据系统

- **视觉教学级别**：自动 / 精简 / 均衡 / 增强
  - `auto` 模式根据课程内容自动判断视觉依赖程度
  - 本地 VLM (Qwen3-VL-2B-Instruct) 仅在 `auto` 模式下本机预检通过时启用
  - 不上传截图、不消耗云端 token
- **视觉证据流程**：
  1. 课程规划阶段生成"像素可回答"的视觉问题
  2. 从关键帧中召回少量候选帧
  3. 本地 VLM 逐任务核验候选帧是否满足成功条件
  4. 通过门槛的图片绑定到对应知识点，未通过的不配图
  5. 每视频单会话、模型只加载一次、compare/detail 顺序执行

## 5. 功能清单

### 5.1 桌面端功能

| 功能 | 说明 |
|------|------|
| 批量队列 | 支持多视频批量处理，全选/取消全选，拖动排序 |
| ASR 引擎选择 | 支持 faster-whisper 和 Qwen3-ASR-0.6B 两种引擎 |
| 引擎降级 | 主引擎失败时自动降级到备用引擎 |
| GPU/CPU 自动切换 | 优先使用 GPU，不可用时降级到 CPU |
| 内容详略档位 | 精简 / 推荐 / 丰富 |
| 视觉教学级别 | 自动 / 精简 / 均衡 / 增强 |
| 编辑偏好 | 通过 `课程资料整理偏好.md` 自定义整理风格（V4.1） |
| 云端优化 | 需用户逐次授权，展示发送内容和预算 |
| 自动处理 | 一键执行全部阶段 |
| 精确取消 | 可随时取消正在执行的任务 |
| 缓存恢复 | 自动复用已完成的中间产物 |
| ETA 估算 | 基于历史样本估算剩余时间 |
| Token/耗时统计 | 记录云端 token 使用和各阶段耗时 |
| 清理缓存 | 二次确认后清空工作区中间文件，不删除最终文档和原视频 |
| 打开产物 | 直接打开原视频、Word、PDF 和产物目录 |
| 单实例互斥 | 防止多进程同时操作同一工作区（V4.1） |
| 产物可见性控制 | 管理生成文档的可见范围（V4.1） |

### 5.2 文档产物

| 格式 | 说明 |
|------|------|
| Markdown | 纯文本，图片使用绝对路径引用，来源链接可点击 |
| Word (.docx) | 通过 Node.js + docx-js 渲染，支持图片、样式、超链接 |
| PDF | 优先使用本机 Microsoft Word 导出；不可用时使用内置 reportlab 渲染 |

### 5.3 来源溯源

- 每个知识点附带 `video-study://play/{video_id}?t={seconds}` 链接
- 桌面端启动时为当前 Windows 用户登记 `video-study://` 协议
- 点击链接直接调用本地播放器（优先 ffplay -ss 精确定位）
- 不启动 Web 服务、不打开网页

## 6. 桌面端使用指南

### 6.1 启动方式

```powershell
# 方式一：命令行
.venv\Scripts\video-study.exe desktop --config config.yaml

# 方式二：双击启动脚本
启动桌面版.cmd
```

### 6.2 界面布局

- **视频列表区**：显示 `Resource/` 目录中的 MP4 文件，可全选/取消全选
- **处理控制区**：ASR 引擎选择、内容详略、视觉教学级别、云端优化开关
- **进度区**：进度条 + 两行浅色滚动日志，显示当前阶段、ETA 和运行时事件
- **结果区**：处理完成后显示产物路径，可直接打开

### 6.3 典型操作

1. **添加视频**：将 MP4 放入 `Resource/` 目录，或通过文件选择器添加
2. **选择引擎**：默认 faster-whisper，可选 Qwen3-ASR-0.6B（需模型已下载）
3. **设置详略**：选择精简/推荐/丰富
4. **开始处理**：点击"开始处理"，系统自动执行全部阶段
5. **查看产物**：处理完成后点击"打开产物目录"
6. **回看来源**：在 Word/PDF 中点击来源时间链接，播放器自动定位

### 6.4 云端优化

- 默认关闭
- 启用时需输入 API Key（可选"记住密钥"保存到 `.env`）
- 发送前展示：发送内容摘要、模型链、调用预算
- 全程受 `max_calls_per_video` 控制（默认 5 次/视频）
- 可随时取消

## 7. 云端与本地模式说明

| 维度 | 本地模式 | 云端模式 |
|------|----------|----------|
| 默认状态 | 启用 | 关闭 |
| 知识整理质量 | 启发式筛选，保证可溯源 | LLM 精炼，更专业完整 |
| 费用 | 免费 | 消耗云端 token |
| 隐私 | 视频不上传 | 发送压缩后的转写文本（不含视频/截图） |
| 授权 | 无需 | 需用户逐次明确授权 |
| 失败行为 | 直接生成离线文档 | 回退到离线模式，保留已有产物 |
| 预算控制 | 不适用 | 单视频全流程共享请求账本（默认 5 次） |
| 模型链 | 不适用 | 4 模型依次故障转移 |
| 编辑偏好 | 不适用 | 支持用户自定义整理偏好 |

## 8. 文档产物说明

### 8.1 文档结构

生成的学习文档包含以下结构：

```
标题
├── 内容导览（overview）
├── 学习目标（learning_objectives）
├── 章节们
│   └── 知识点们
│       ├── 正文（paragraph）
│       ├── 规则列表（rule_list）
│       ├── 步骤（steps）
│       ├── 案例（example）
│       ├── 易错点（pitfall）
│       ├── 视觉证据组（visual_group）— 含图片和看图重点
│       ├── 理解提示（understanding_tip）
│       └── 来源链接（source_links）— video-study:// 回看
├── 课程复习
│   ├── 知识主线
│   ├── 关键规则清单
│   └── 待回看与未展开问题
└── 完整转写（可选）
```

### 8.2 内容详略档位

| 档位 | 定位 | 知识点密度 | 细节保留 |
|------|------|-----------|----------|
| 精简 | 复习提纲 | 每章 1–3 个 | 只保留最关键定义、规则和结论 |
| 推荐 | 标准课程笔记 | 每章 2–6 个 | 保留必要解释、步骤、案例、适用条件、易错点 |
| 丰富 | 完整课程讲义 | 每章 2–6 个 | 尽量保留推导过程、多案例、边界条件、易错点和复习提示 |

### 8.3 Schema 版本

- **Schema v1**：旧版文档格式，正文以 explanation + 列表字段为主
- **Schema v2**（默认）：以 `content_blocks` 为正文唯一事实源，Markdown、Word、PDF 通过只读兼容 view 保持同源

### 8.4 编辑偏好（V4.1）

用户可在项目根目录创建 `课程资料整理偏好.md` 文件，用自然语言描述整理偏好（如"侧重实操步骤、弱化理论推导""按时间线组织"等）。系统会：

1. 加载并归一化偏好文本（最多 4000 字）。
2. 在云端规划阶段，将偏好注入 LLM prompt，生成 `EditorialDecision`（结构模式、核心主线、焦点优先级、序列策略）。
3. 编辑决策贯穿规划和写作阶段，影响章节组织和内容详略。
4. 偏好的 SHA-256 指纹记录在产物中，确保可审计。
5. 文件缺失时使用默认偏好；可通过 `restore_default` 恢复默认。

## 9. 安全与隐私

### 9.1 数据安全

- 视频文件始终使用本地绝对路径，不上传、不复制
- 云端模式仅发送压缩后的转写文本（CourseIR 投影），不含视频或截图
- 删除缓存与产物不会删除源 MP4

### 9.2 密钥安全

- API Key 仅在用户启用"记住密钥"后保存到 `.env`
- `.env` 已被 `.gitignore` 忽略
- 禁止在代码、日志或文档中输出密钥

### 9.3 云端授权

- 云端推理默认关闭
- 真实云调用前必须逐次说明：发送数据、端点、模型链和预算
- 获得用户明确授权后才发起请求
- 不得仅为测试配置而发起真实 API 请求

### 9.4 本地 VLM 安全

- 本地 VLM 为 `auto` 模式：仅在本机模型、运行时和 CUDA 预检通过时启用
- 不上传截图、不消耗云端 token
- 缺能力时明确降级，不静默失败
