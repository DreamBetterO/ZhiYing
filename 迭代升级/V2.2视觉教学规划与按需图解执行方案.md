# V2.2 视觉教学与按需图解执行任务书

> 状态：已实施并验证（2026-08-10）；后续被 V3.0 统一课程 IR 方案取代，保留为历史架构依据。

## 目标

- 内容详略与图片丰富度独立配置。
- 先确定知识点的视觉职责和成功条件，再按像素内容选图。
- 强 PPT/图表/软件课程增加有效图解，语音主导课程不强行增图。
- 失败时保持 V2.1.1 的 `no_match`，不恢复时间最近帧。

## 不要重做

V2.1.1 已有：VisualEvidence 唯一图片权威、场景聚类/课程级仲裁、无像素证据拒绝、原子 `visual_group`。V2.2 在其上扩展，不重写这些逻辑。

## 必须改动

| 部分 | 当前 | V2.2 |
|---|---|---|
| 图片配置 | 被内容档位间接控制 | 新增 `visual_teaching.level=auto|minimal|balanced|enhanced` |
| 课程规划 | 无视觉画像 | LessonPlan 增加 `visual_profile` |
| VisualNeed | 只有 `required/question` | 增加职责、成功条件、数量和解释深度 |
| 图片文字 | 无标准 OCR provider | 可选 RapidOCR，仅跑 canonical/targeted frame |
| 图片判断 | fallback | 可选 Qwen3-VL-2B：最多 4 图比较，1 图/ROI 复核 |
| VisualEvidence | 有像素证据门 | 增加职责完成情况和视觉答案 |
| 写作 | 通用视觉解释 | 按定位、解释、步骤、对比、证据、回顾组织 |

不引入 LangGraph、全视频 VLM、向量库、4B/8B、量化栈、本地服务或重型评测。

## 数据合同

新增字段必须有默认值；旧 JSON 可读取；更新 schema/cache 签名。

```json
{
  "visual_profile": {
    "course_form": "chart_analysis",
    "visual_dependency": "high",
    "dominant_visuals": ["chart", "software_ui"],
    "recommended_level": "enhanced",
    "signals": ["图表术语密集"]
  },
  "visual_need": {
    "required": true,
    "question": "哪根 K 是起点，它与中枢边界是什么关系？",
    "role": "explain",
    "target_count": 1,
    "max_count": 1,
    "sequence_mode": "single",
    "explanation_depth": "teaching_note",
    "success_criteria": ["看清起点 K", "定位边界", "说明关系"],
    "reason": "依赖空间关系"
  },
  "visual_evidence_extension": {
    "visual_role": "explain",
    "visible_evidence": ["三段走势经过同一区间"],
    "criteria_met": ["定位边界"],
    "criteria_missing": [],
    "visual_answer": "重叠区位于两条水平线之间",
    "needs_detail_pass": false
  }
}
```

枚举：

- `course_form`：`speech_dominant|slide_dominant|screen_demo|chart_analysis|talking_head|mixed`
- `role`：`locate|explain|procedure|compare|evidence|recap`
- `sequence_mode`：`single|comparison_pair|progression_grid`

`select` 必须满足：候选 ID 合法、`visible_evidence` 非空、关键成功条件已满足。置信度不能替代这些条件。

## 固定流程

```text
LessonPlan 同次生成视觉画像/合同
→ 复用场景聚类与 canonical frame
→ 可选 OCR
→ 问题、OCR、场景类型、时间弱先验召回最多 6 个场景
→ 确定性裁剪到最多 4 图交给 VLM 比较/拒绝
→ 必要时复核 1 图/ROI
→ 写作器消费最终 VisualEvidence
→ 复用 visual_group 输出 Markdown/Word/PDF
```

- 画像只决定默认倾向，不能给全部知识点强行配图。
- OCR 提字；VLM 判断文字/区域/走势与问题的关系。
- 写作器不能重选图片或创造视觉事实。
- 增强档不降低证据门；`no_match` 是正常结果。

## 验收与停止

必须满足：

- 旧配置/数据兼容；内容和图文档位独立；
- 每张图可追溯到 VisualNeed、VisualQuestion、VisualEvidence 和时间戳；
- 无编造候选 ID、明显错图、近重复图或伪造像素证据；
- 图解说明“看哪里、看到什么、为什么重要”；
- 语音课程自动模式不强行增图；Word/PDF 无拆组和重复图注。

若 2 图低预算仍 OOM、模型频繁编造、固定问题不优于 OCR+规则或图文质量未改善，停止叠加技术。关闭 OCR/VLM，回退到 V2.1.1 的 `no_match`，不得移除其正确性保护。
