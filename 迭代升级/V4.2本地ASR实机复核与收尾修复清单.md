## 2. 必须修复

### P0：补齐并统一 Qwen 隔离 runtime

责任文件：`packing/script/copy_runtime_packages.py`、`packing/script/create_portable_runtime.ps1`、`packing/script/verify_portable.py`、`config.yaml` 及便携配置。

- 当前开发 overlay 有 `qwen-asr 0.0.6`、`transformers 4.57.6` 和 `torch 2.7.1+cu128`，但缺少 `nagisa`、`soynlp`、`qwen-omni-utils` 等官方依赖；`from qwen_asr import Qwen3ASRModel` 不能通过。
- 当前便携 runtime 构建种子没有 `qwen-asr`。现有 `0.4.1` 便携包的 runtime 甚至不含 `qwen_asr`，不得标记为 Qwen3-ASR 可用。
- 将 `qwen-asr==0.0.6` 纳入 runtime 依赖闭包，冻结其兼容的 Transformers/Torch 组合；不安装 `vllm` 可选扩展，不引入 WSL、Docker、HTTP 服务或端口。
- 开发版与便携版最终都应使用自包含 runtime Python，避免依赖目标电脑的 Conda。Qwen3-VL 必须在同一冻结组合下继续通过预检和真实短烟测。
- runtime 构建后必须执行依赖一致性检查和以下真实导入：`qwen_asr`、`Qwen3ASRModel`、`torch`、`transformers`、`soundfile`。

该阶段涉及安装/重建依赖，执行前必须单独获得用户授权；不得重新下载或覆盖模型权重。
