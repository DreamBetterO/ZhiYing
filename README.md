# 知影 · 视频知识工作台

> 原生 Windows 桌面视频整理工具，将教学视频转化为可溯源的结构化学习文档。  
> 当前版本：**V6.1 / 产品版本 1.0.0rc1**

---

## 产品简介

知影是一款面向学生、自学者和培训讲师的**本地优先**视频知识整理工具。它将 MP4 视频或公开视频链接自动处理为带有时间戳回看链接的 **Markdown / Word / PDF** 学习资料，让"看完视频，带走笔记；阅读笔记，秒回视频"成为现实。

- **可溯源**：每个知识点都带有原视频时间戳链接，点击即回看
- **离线优先**：语音识别、知识整理、文档生成均可完全离线运行
- **多格式输出**：同时生成 Markdown、Word、PDF 三种格式
- **隐私安全**：视频不上传，云端默认关闭，密钥不提交

📖 **[查看完整使用说明 →](docs/项目文档/软件介绍.md)**

## 核心链路

```text
本地 MP4 / 视频链接 → 音频提取 → 语音识别 → 关键帧提取 → 知识整理
    → 编辑 Harness（文档规划+章节写作+质量审计）→ Markdown → Word → PDF
```

## 快速启动

### 方式一：双击启动（推荐）

直接双击根目录下的 **`启动桌面版.cmd`**。

### 方式二：命令行启动

```powershell
conda activate ImageT10
set PYTHONPATH=%CD%\src
python -m video_study desktop --config config.yaml
```

## 界面与功能速览

| 功能 | 说明 |
|------|------|
| 本地视频整理 | 选择 MP4 文件，一键完成语音转写、知识整理、文档生成 |
| 视频链接解析 | 粘贴 B 站等链接，自动预检、下载、整理（V5.0） |
| 批量队列 | 多视频批量处理，支持全选/取消全选、拖动排序 |
| 本地/云端双模式 | 默认本地离线；可选云端 LLM 优化获得更专业的文档（V6.1） |
| 时间戳溯源 | 文档内嵌 `video-study://` 链接，点击直接调用本地播放器定位 |
| 公式原生渲染 | Word 中数学公式以原生 OMML 渲染（V6.1） |
| 视觉证据绑定 | 自动筛选关键画面并绑定到对应知识点 |
| 缓存恢复 | 自动复用中间产物，移除重加不丢失状态 |
| 精确取消 | 200ms 内取消任务并清理运行时缓存 |
| 缓存清理 | 二次确认后清空工作区中间文件，保留原视频和产物 |

详细界面说明、操作步骤与常见问题请参阅 **[软件介绍](docs/项目文档/软件介绍.md)**。

## 开发状态

本项目当前处于 **V6.1 / 1.0.0rc1** 阶段，核心架构与功能已趋于稳定，主要特征如下：

- **编排器**：V6.0 全面迁移至 LangGraph（`GraphRuntime`），为唯一生产编排器
- **编辑 Harness**：V6.1 引入受控 Function Calling 编辑子图，LLM 拥有文档规划、写作、审计、修订的阶段性编辑权
- **本地确定性链**：保留完整的无 LLM 本地完成路径，确保离线场景可用
- **Document v3.1**：组件树为唯一事实源，Markdown/Word/PDF 三端原生渲染
- **三级降级**：tool_native → structured_only → local_deterministic，失败时自动降级并透明标注
- **证据纠错覆盖层**：V6.1 引入本地疑点检测 + 云端纠错，不发送完整 transcript

详细架构、模块边界、测试策略与验收流程请参阅 [`docs/项目文档/开发文档.md`](docs/项目文档/开发文档.md)。

## 配置与安全

| 文件 | 用途 | 说明 |
|------|------|------|
| `config.yaml` | 本地处理、渲染、桌面水印等配置 | 可提交 |
| `api.yaml` | 云端端点、模型链与预算配置 | 不含密钥，可提交 |
| `.env` | API Key | 仅在用户启用"记住密钥"后生成，已被 `.gitignore` 忽略 |

> 禁止把 `.env` 中的密钥输出到日志、文档或提交到仓库。删除缓存与产物不会删除源 MP4。
